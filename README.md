# Moss365

**Moss365** is een beheerapp voor **Active Directory, Entra ID en Exchange Online** (Microsoft 365), voor IT-diensten
die één of meer organisaties (tenants) beheren. Gebruikers, groepen, gedeelde postvakken, rooms, gasten, licenties,
beveiliging en Conditional Access op één scherm, met de geschiedenis van de organisatie door de tijd.

> **Status**: in voorbereiding. De app bestaat al als interne versie (0.9) en komt naar deze openbare repository volgens
> de roadmap. Er is hier nog geen download.

## Hoe Moss365 werkt

- **Elke wijziging is een plan**: eerst een voorbeeld, dan een bevestiging, dan het logboek. Ongedaan maken waar het kan.
- **De app kan niet meer dan jouw account**: gedelegeerde rechten, geen geheimen op schijf of in een log.
- **Rollen** in de app (Lezer, Helpdesk, Beheerder, Auditor, Appbeheer), afgedwongen tot in de motor.
- **Meerdere tenants**, strikt gescheiden, met een eigen databank per tenant.
- **Momentopnamen**: hoe de organisatie eruitzag op elke datum, en het verloop van elke indicator.
- **Geen telemetrie**: gegevens blijven bij de organisatie.

## Open source

Moss365 wordt open source onder de **EUPL-1.2** (de open-sourcelicentie van de Europese Unie), met een
bijdrageovereenkomst voor bijdragen van buitenaf. Het licentiebestand komt bij de eerste code (zie de roadmap,
hoofdstuk 11 en 12); tot dan zijn er nog geen rechten verleend. Ondersteuning, installatie en opleiding kunnen later betalend aangeboden worden; de app zelf blijft vrij.

Moss365 is niet verbonden met Microsoft. Microsoft 365, Entra ID en Exchange Online zijn merken van Microsoft.

## In English

Moss365 is a management app for Active Directory, Entra ID and Exchange Online, for IT teams managing one or more
Microsoft 365 tenants. Every change is a plan you preview and confirm, everything is logged, and the app keeps snapshots
of each organisation over time. Code and documentation are moving to English; the interface will be available in Dutch, English, Brazilian Portuguese, French and German (following the Windows display language by default). Licence: EUPL-1.2. See the
roadmaps above (in Dutch). Moss365 is not affiliated with Microsoft.
